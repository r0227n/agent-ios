# E2E テストレポートフォーマット仕様

このドキュメントは E2E テスト結果のレポート作成フォーマットを定義します。

## ファイル命名規則

```
e2e-report-<platform>-<timestamp>.md
```

例:
- `e2e-report-ios-20260125-103045.md`
- `e2e-report-android-20260125-143022.md`

## 状態の定義

| 状態 | 記号 | 説明 |
|------|------|------|
| 成功 | ✅ | コマンドが期待通りに動作 |
| 失敗 | ❌ | エラーが発生または期待と異なる動作 |
| スキップ | ⏭️ | 意図的にテストを実施しなかった |

## 記入例

### 成功例

```markdown
| 1 | tap @e1 | ✅ ボタンが正常にタップされた |
```

### 失敗例

```markdown
| 2 | long-press center | ❌ Error: Failed to get screen size |
```

### スキップ例

```markdown
| 3 | app uninstall | ⏭️ 環境への影響を考慮 |
```

## 優先度の定義

| 優先度 | 説明 |
|--------|------|
| 高 | コア機能に影響、即時対応が必要 |
| 中 | 一部機能に影響、次回リリースまでに対応 |
| 低 | 軽微な問題、時間があれば対応 |

## テンプレートの使用方法

1. このフォーマットに従ってレポートを作成
2. 各セクションを実際のテスト結果で埋める
3. 不要なセクションは削除可能
4. 追加の情報があれば付録に追加
